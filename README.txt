GradeBook Pro v11 — Professional Report Design
This release improves report PDF/print and Word export styling with a branded navy/teal/gold palette, clearer KPI cards, colored visual bars, refined typography, spacing, and A4 print layout. Existing records and calculations are unchanged.

Update:
1. Export your local backup first.
2. Extract this ZIP and replace index.html and service-worker.js in the GitHub repository root.
3. Commit and wait for Pages deployment.
4. Open the app and hard-refresh (Ctrl+Shift+R).
5. When printing to PDF, enable “Background graphics” in Chrome print settings for the best color fidelity.

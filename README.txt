GRADEBOOK PRO — INSTALLABLE APP PACKAGE

Files: index.html, manifest.webmanifest, service-worker.js, icons.

IMPORTANT: PWA installation and offline caching require HTTPS hosting (or localhost). Opening index.html directly works as a local web page, but browser install/offline service-worker features are not enabled from file://.

Free hosting option (GitHub Pages):
1. Sign in to GitHub and create a new public repository, e.g. gradebook-pro.
2. Upload all files in this folder to the repository root.
3. In repository Settings > Pages, choose deploy from branch, select main and /(root), then Save.
4. Open the generated HTTPS Pages address in Chrome. On Android, use Chrome menu > Install app or Add to Home screen. On desktop Chrome/Edge, use the install icon in the address bar or menu.
5. Open the installed app online once, then it can load offline after its assets have been cached.

AUTOMATIC LOCAL SNAPSHOTS: Data saves to browser storage and keeps up to 20 recent automatic snapshots. Use “Restore auto-backup” to recover a snapshot. Snapshots are on the same device/browser only; they are not cloud backups and can be lost if browser/site data is cleared or the device is lost. Keep the manual backup/export option for disaster recovery.
